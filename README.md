# qemu-system-ia64-windows-gui

## Overview
**qemu-system-ia64-windows-gui** is a simple GUI frontend for `qemu-system-ia64` on Windows.  
It allows you to easily create, boot, and manage your virtual machines.

## Features
- **Automatic OS Detection:** Automatically detects some guest operating systems that require special configurations.
- **GUI-Based Management:** Easily configure and manage your VMs using graphical wizards and menus.

## Roadmap
- **Guest Tools for Windows:** Support for drag-and-drop, clipboard sharing (copy and paste), dynamic display resolution, time synchronization, and more.
- **Automated Optimized QEMU Builds:** Automatically build QEMU optimized for each host machine's configuration (potentially including Profile-Guided Optimization based on real guest workloads).
- **Expanded OS Support:** Broader guest OS recognition and configuration support.

## Language support
- For UI language, currently only Japanese and English are supported.
- You can help us improve or add language supports, by submitting issues or pull requests.
- QEMU might have difficulty while handling files with non-ASCII characters.
